Known Bugs
==========

W2k-does-not-restart (PnP only?). This happens always when CGF1Common
still lives while windows shut down. I think it freezes the computer if
going to standby mode too (but I can't check this since I no longer have
PnP board).

We encountered some recording problems on one of borrowed PnPs.

My GUS Classic sometimes does not generate wavetable IRQs
(playback / recording stops or doesn't start). I still don't
know if it is:
  a) driver bug, or
  b) GF1 bug, or
  c) my board bug

GF1 recording has never been tested well, because of those wavetable
IRQ problems. It probably doesn't work.

Multiple GUS cards can't be probably used. The only "bug" I am aware
of is the way handle to physical device object is "passed" to
CGF1Common object. See notes "bbsgf1.cpp" for more notes on this.
